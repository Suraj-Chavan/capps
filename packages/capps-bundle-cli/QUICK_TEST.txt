STEP 2: QUICK TESTS (5 minutes)
═════════════════════════════════════════════════════════════════════════════

Test 1: Version
───────────────
capps-bundle version
Expected: capps-bundle version 1.0.0

Test 2: Help
────────────
capps-bundle help
Expected: Shows all commands with examples

Test 3: Create Test App
───────────────────────
mkdir -p ~/test-capps-app/public/src
cd ~/test-capps-app
cat > public/assets.json << 'EOF'
{
  "app_name": "test-app",
  "bundler": "vite",
  "build": {
    "entry_points": { "app": "src/index.js" }
  }
}
EOF
echo "console.log('test');" > src/index.js

Test 4: Validate
────────────────
capps-bundle validate
Expected: ✓ Configuration validation passed!

Test 5: Test Error Handling
────────────────────────────
# Change bundler to invalid name
sed -i 's/"vite"/"rollup"/' public/assets.json
capps-bundle validate
Expected: ✗ Invalid bundler: "rollup" with supported list

Test 6: Test All Bundlers
──────────────────────────
sed -i 's/"rollup"/"webpack"/' public/assets.json
capps-bundle validate    # Shows: Bundler: webpack

sed -i 's/"webpack"/"vite"/' public/assets.json
capps-bundle validate    # Shows: Bundler: vite

sed -i 's/"vite"/"esbuild"/' public/assets.json
capps-bundle validate    # Shows: Bundler: esbuild

Test 7: Package Management
───────────────────────────
capps-bundle list-pkg
Expected: No packages directory found (OK - first time)

Test 8: Debug Output
────────────────────
capps-bundle validate --debug
Expected: Shows debug info with → arrows

Test 9: Unknown Command
───────────────────────
capps-bundle unknowncmd
Expected: ✗ Unknown command with help suggestion

Test 10: Clean Command
──────────────────────
capps-bundle clean
Expected: Gracefully handles missing dist directory

TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

If capps-bundle not found:
──────────────────────────
node packages/capps-bundle-cli/bin/capps-bundle.js validate

If npm link fails:
──────────────────
npm unlink -g @capps/bundle-cli
cd packages/capps-bundle-cli
npm link

If permission denied:
─────────────────────
chmod +x packages/capps-bundle-cli/bin/capps-bundle.js
