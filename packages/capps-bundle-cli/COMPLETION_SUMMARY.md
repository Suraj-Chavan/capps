## Production Default Design Rationale

### Why Default to Production?

1. **99% Use Case**: Most developers use the bundled CAPPS framework
2. **Simpler User Experience**: No cssSource prompt needed during init
3. **Vue CLI Output**: Vue CLI generates `dist/` directory (production standard)
4. **Fallback Support**: Automatically falls back to `public/css` if dist doesn't exist
5. **Advanced Override**: Users who need development mode can edit assets.json

### How It Works

**Priority chain for cssSource**:
1. `assets.json` tailwind.cssSource (if explicitly set)
2. Default: 'production' (hardcoded fallback)

**Priority chain for cssSource paths**:
1. `assets.json` tailwind.cappsUIPath (if set)
2. Auto-detection from relative paths
3. Fallback to hardcoded path: `D:\credence\Servers\Funds\Apps\ui\capps`
